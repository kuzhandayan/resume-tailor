Job Overview

We are seeking a Full Stack Software Developer to support and evolve our web applications and cloud‑based platforms. This role will focus on stabilizing, enhancing, and selectively expanding existing systems while contributing to new development initiatives where there is clear business value.

This position is well‑suited for a versatile engineer who is comfortable working across the stack and collaborating closely with product, DevOps, and QA partners. The scope and long‑term structure of the role may evolve based on organizational needs, delivery velocity, and platform maturity.

What You'll Do

Design, develop, and maintain full‑stack web applications using modern frameworks and cloud services
Build responsive and maintainable front‑end interfaces using React and/or Angular
Develop secure, scalable back‑end services using .NET
Work with PostgreSQL and SQL Server for data modeling, querying, and performance tuning
Develop and deploy applications using Docker/containerized environments
Leverage AWS cloud services for hosting, automation, monitoring, and scalability
Participate in code reviews, architectural discussions, and Agile ceremonies
Troubleshoot and resolve issues across application, infrastructure, and data layers
Contribute to improving engineering standards, tooling, and documentation
Collaborate closely with product managers, QA, DevOps, and other engineers
